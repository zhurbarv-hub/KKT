# KKT System

Система управления контрольно-кассовой техникой и дедлайнами услуг.

## Возможности

- 📊 Dashboard со статистикой дедлайнов
- 👥 Управление клиентами и их ККТ
- ⏰ Отслеживание сроков услуг (ОФД, ФН, ЭЦП и др.)
- 🤖 Telegram бот для уведомлений
- 📱 PWA - работает как приложение на телефоне
- 🌙 Тёмная/светлая тема

## Технологии

**Backend:** Python, FastAPI, SQLAlchemy, PostgreSQL, Redis  
**Frontend:** React 18, TypeScript, Vite, Tailwind CSS  
**Bot:** aiogram 3, Redis FSM  
**Deploy:** Docker, Docker Compose
